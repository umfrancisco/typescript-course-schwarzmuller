# Understanding TypeScript (Udemy Course)

A comprehensive course focused on learning **TypeScript**, from fundamental concepts to advanced features, practical workflows, and real-world applications with React, Node.js, and Express from Maximilian Schwarzmüller.

The goal of this repository is to document my learning journey, reinforce TypeScript fundamentals, and develop the skills needed to build more reliable, maintainable, and scalable JavaScript applications.

## About the Course

TypeScript is a strongly typed programming language built on top of JavaScript and developed by Microsoft. It extends JavaScript with static typing and additional development features, helping developers catch errors earlier, improve code quality, and build more maintainable applications.

Throughout this course, I explore how TypeScript works, how its compiler transforms TypeScript code into JavaScript, and how its features can be applied to different development environments and projects.

The course also covers TypeScript integration with popular technologies such as **React**, **Node.js**, and **Express**.

## Technologies and Tools

- **Language:** TypeScript, JavaScript
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Build Tools:** Webpack
- **Compiler:** TypeScript (`tsc`)
- **Runtime:** Node.js
- **Libraries:** Zod and other third-party JavaScript libraries
- **Configuration:** `tsconfig.json`

## Learning Objectives

By completing this course, I aim to:

- Understand TypeScript's type system and how it improves JavaScript development.
- Write safer and more maintainable code using static typing.
- Understand the TypeScript compiler and its configuration.
- Apply object-oriented programming principles with TypeScript.
- Work confidently with interfaces, generics, utility types, and advanced type manipulation.
- Understand modern TypeScript features and their practical applications.
- Integrate TypeScript into React applications.
- Develop backend applications using TypeScript, Node.js, and Express.
- Configure different TypeScript development and build workflows.

## Prerequisites

- Basic JavaScript knowledge.
- Familiarity with programming fundamentals.
- Previous TypeScript experience is not required.
- Knowledge of ES6 is helpful but not mandatory.
